NEC 200 ms

The simplest maintained build. It uses NEC address 0x00 and sends command 152, 31, or 62 from SW1, SW2, or SW3.

  • Full 9 ms / 4.5 ms NEC header.
  • Full frame repeats every 200 ms while held.
  • SW1 > SW2 > SW3 priority.
  • Three-second awake window after reset; no post-release window.

Configurable IRC2

Each button stores an address, command, and protocol selector in a 64-byte page at 0x08000800.

  • Magic IRC2 plus checksum over bytes 0x00..0x0F.
  • Blank, corrupt, unsupported, or old IRC1 pages use factory NEC commands 152 / 31 / 62.
  • Full configured frame repeats every 200 ms.
  • Six-second SWIO window after reset and release.

Samsung 110 ms

Samsung address 0x07. SW1 is Power (0xE0E040BF), SW2 is Enter (0xE0E016E9), and SW3 sends the full 7 → 1 → 5 → 0 → Enter macro.

  • SW1/SW2: one full frame, then the short repeat frame on a fixed 110 ms start-to-start raster.
  • SW3: 500 ms between digits; the complete macro repeats 110 ms after finishing if held.
  • Six-second SWIO window after reset and release.
