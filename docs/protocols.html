On the wire

NEC, Samsung32, and IRC2

Transmission is active-low on PA2. A mark turns the carrier on; a space turns it off.

NEC

Standard 16-bit address / 8-bit command format. This project sends an 8-bit address followed by its bitwise complement.

  • Leader: 9 ms mark, 4.5 ms space.
  • Bit: 560 µs mark, then 560 µs (0) or 1690 µs (1) space.
  • End: 560 µs mark.
  • Address 0x00; commands 152, 31, 62 for SW1, SW2, SW3.

Samsung32

Uses the common extended Samsung header and LSB-first data coding.

  • Leader: 4500 µs mark, 4500 µs space.
  • Bit: 560 µs mark, then 560 µs (0) or 1690 µs (1) space.
  • End: 560 µs mark.
  • Address byte 0x07 for this variant.

Samsung short repeat

SW1 and SW2 send a short repeat frame every 110 ms while held:

  • 4500 µs mark
  • 4500 µs space
  • 560 µs mark
  • 560 µs space
  • 560 µs mark

The start-to-start raster is fixed rather than adding delay after the frame.

Configurable variant

IRC2 page at 0x08000800

The browser patches the 64-byte blank page in ir_remote_template.bin. The same codec is shipped as web/ir.js and tested without hardware.
