Build, test, verify, flash

The checked-in hashes were produced with xpack RISC-V GCC 15.2.0-1. A clean build regenerates every source-backed binary and runs both protocol tests.

Prerequisites

  • A POSIX shell or Git Bash.
  • Node.js 20 or newer.
  • xpack riscv-none-elf-gcc-15.2.0-1.
  • GNU Make only if you want to use the per-variant Makefiles.

The top-level scripts call GCC, objcopy, and size directly, so they also work where the available make is not GNU Make.

One-command build

TOOLCHAIN_DIR=/path/to/xpack-riscv-none-elf-gcc-15.2.0-1/bin \
  sh scripts/build-all.sh

Set CROSS to another prefix if needed. The default is riscv-none-elf-.

What the build checks

Samsung frames

Reconstructs all six 32-bit values from the C constants and compares them with published codes.

IRC2 codec

Runs the browser's own build/parse functions against the firmware layout, checksum, and rejection cases.

Artifact hashes

Verifies all ten committed .bin, .hex, and template files against manifests/SHA256SUMS.

Flash at the correct address

Every firmware .bin starts at 0x08000000. The 2112-byte configurable template is a combined code/config image for the web programmer, not a normal source build.

  1. Remove the remote's battery before connecting WCH-LinkE.
  2. Put the programmer in WCH-LinkRV / RISC-V mode.
  3. Connect SWIO, GND, and the appropriate target supply. Do not press a button while the programmer is attaching unless the variant's link window is already open.
  4. Flash the .bin at 0x08000000, or load the .hex in WCH-LinkUtility.
  5. For configurable or Samsung firmware, keep a remote button held during Detect/Program so the six-second SWIO window stays open.

Web-flasher integration

The configurable variant can copy its template into an existing WCH-WebLink asset directory without hardcoded paths:

WEBFW=/path/to/WCH_WebLink/data/www/fw \
  TOOLCHAIN_DIR=/path/to/xpack-riscv-none-elf-gcc-15.2.0-1/bin \
  sh variants/configurable-irc2/build.sh

The complete ESP32-C3 bridge and browser UI live in the separate private [Bear-Buddy web flasher repository](https://github.com/foerfelixir/bear-buddy-webflasher).
