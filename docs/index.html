Inputs

SW1 · SW2 · SW3

PC4, PC2, and PC1. Active low with internal pull-ups. Priority is SW1 > SW2 > SW3.

Output

PA2 / TIM1_CH2N

Hardware-generated 38.46 kHz carrier. The CPU only gates marks and spaces.

Power

Standby between presses

EXTI falling-edge wake. Configurable and Samsung builds keep a six-second SWIO window.

Firmware families

Pick the behavior you need

984 B · source + binary

NEC 200 ms

Address 0x00. SW1 sends 152, SW2 sends 31, SW3 sends 62. Full NEC frames repeat every 200 ms while held.

Variant details

1360 B · source + binary

Configurable IRC2

NEC or Samsung per button. A checksummed 64-byte flash page stores address, command, and protocol.

Variant details

1308 B · source + binary

Samsung 110 ms

Power, Enter, and the full 7150 + Enter macro. SW1/SW2 use Samsung short repeats; SW3 always sends the whole macro.

Variant details

1276 B · binary only

NEC-only backup

Historical IRC2-era image. The exact source was not retained; the original binary and template are preserved.

Variant details

Hardware was traced, not supplied

The schematic was reverse-engineered by physically tracing the PCB lines and continuity. It is not a manufacturer schematic. Verify it against your own board before powering or fabricating anything.

Build, test, and verify

TOOLCHAIN_DIR=/path/to/xpack-riscv-none-elf-gcc-15.2.0-1/bin \
  sh scripts/build-all.sh
node scripts/verify-manifests.mjs

The build regenerates all source-backed images, checks Samsung frame values, validates the IRC2 browser codec, and verifies all ten committed artifacts against SHA-256.
